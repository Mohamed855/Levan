# تصحيح الالتزام بهوية المنصة والقالبين

هذا التصحيح يستبدل قرارات العرض المخالفة في التنفيذ السابق بناءً على توجيه المستخدم الصريح.

1. مطابقة صفحات index مع الإسنادات: نفس slots الإحصائيات والفلاتر والجدول، أدوات DataTables داخل الشريط المعتاد، ومكوّنات x-actions للأزرار.
2. جعل إضافة وتعديل الحملة والإقفال نموذجًا واحدًا دون stepper أو خطوة مراجعة مستقلة. جميع الحقول الثابتة والشرطية ورفع الملفات والاختيار تستعمل مكوّنات x-form القائمة.
3. حذف استبدال صفحات التقارير بملاحق حملات أو إقفال عامة. استعمال صفحات القالبين الأصلية وربط كل سجل بمواضعه، مع تكرار الصفحة الأصلية عند تكرار الحملات، وترك القيم غير المسجلة فارغة. الصفحة التي لا تملك بيانات لا تظهر.
4. اختبار مواضع القالب الأصلي، والقيم الجزئية والصفر، وعزل بيانات الحملات المتكررة، واختبار واجهات الإدخال والقوائم بصريًا ووظيفيًا.

لا يغيّر التصحيح مخطط البيانات أو قواعد الإقفال أو حماية اللقطة أو آلية استبدال التقريرين الناجحين. لا تصميم جديد للتقارير أو الواجهات.

## توجيه المستخدم: التقرير مرجع حقول الإدخال

- حذف أنواع جوجل/أخرى والمؤشرات العامة التي أضافها التنفيذ دون مواضع أصلية.
- توفير أقسام التخطيط والهوية والترويج والكتيب والمنصة واللوحات والوسطاء داخل إدارة الحملات باستخدام مكونات النظام، وتخزين تفاصيلها في JSON الموجود.
- ربط كل سجل بصفحته الأصلية وتكرارها عند تعدد السجلات؛ الحقول الجزئية تبقى جزئية دون نصوص مفترضة.
- إتاحة عدد ومقاس لوحات كل عقار، ونص النتائج وتاريخ وأدلة فك اللوحات في الإقفال، مع المحافظة على الأقفال وإعادة التوليد.
- التحقق من الحفظ والتعديل والحذف، ملكية العقار/الأدلة، الواجهات الفعلية، وملفات PDF الأصلية.
