# تصحيح عرض دورة المزادات بعد ملاحظات المستخدم

تقرير التسليم السابق لا يُعد اعتمادًا للتغييرات المرئية: المستخدم رفض استبدال صفحات التقارير بملاحق عامة، واختلاف القوائم والنماذج عن أسلوب المنصة.

## التصحيح المنفذ

- القوائم الثلاث تتبع صفحة الإسنادات: مكوّن صفحة الجدول، بطاقات الإحصائيات، فلاتر المكوّنات والتواريخ، وأدوات البحث والتصدير والإضافة داخل شريط DataTables.
- أزرار الصفوف تستعمل `x-actions.row/show/edit/delete` والأيقونات المعتمدة.
- الحملة والإقفال نموذجان من صفحة واحدة، دون stepper أو خطوة مراجعة منفصلة. جميع الحقول الثابتة والشرطية والاختيارات والملفات والحذف الاختياري للمرفقات تستعمل مكوّنات `x-form` القائمة. JavaScript يغيّر إظهار المكوّن وتعطيله فقط.
- مسار التقارير الحالي يستعمل صفحات Haram/Asir الأصلية بدل ملاحق بيانات الحملات والإقفال التي أضيفت في التنفيذ السابق. الحملات المتكررة تستعمل تكرار الصفحة الأصلية مع سياق مستقل للبيانات والروابط.
- غياب حقل لا يتحول إلى صفر أو شرطة بديلة، وتبقى القيمة صفرًا حين يسجلها المستخدم. الصفحات الخالية من البيانات الخاصة بها لا تضاف. لا رسائل حشو عن غياب الأدلة داخل صفحات القالب.
- أدلة القنوات التي لها مواضع أصلية تملأ تلك المواضع، ويستعمل تجاوز عدد الصور تكرار الصفحة الأصلية. الأدلة القديمة غير المرتبطة بحملة لا تُنسب عشوائيًا إلى حملة جديدة.
- الصفحة الأصلية للكتيب تستعمل أدلة الحملة عند اختيار دور رابط الكتيب، بما يشمل الملفات المخزنة بقسم قناة الحملة.
- أعيد استبدال الشعارات الثابتة في صفحة المنصة والفيديو ضمن مواضعها الأصلية، مع الاحتفاظ بالتصميم.

## التحقق الفعلي

- حزمة التقارير والمزادات بعد استكمال مطابقة الإدخال: 171 اختبارًا و1620 تحققًا، دون إخفاق، على قواعد الاختبار المعزولة.
- فحص PHP لـ97 ملفًا متغيرًا والتنسيق وفحص الفروقات نجحوا؛ بناء الواجهة نجح.
- اختبار المتصفح شغّل الثيم والمكوّنات وسكربت التحقق المشترك، وأرسل النموذجين، واختبر الحقول الشرطية والصفر وأشرطة الجداول وأزرار الأيقونات.
- معاينات الواجهات: `output/cycle-review/*-native.png`.
- معاينات PDF اصطناعية: `output/pdf/cycle-proof`، تتضمن بيانات جزئية وحملات متكررة وأدلة متعددة.
- مراجعة مستقلة كشفت فقدان بعض صور التواصل وأدلة الكتيب، وأُصلحت الحالات باختبارات إعادة إنتاج. إعادة المراجعة لم تجد مشكلة مهمة متبقية في هذه الإصلاحات.

## توجيه المستخدم اللاحق

حسم المستخدم أن حقول التقريرين هي المرجع، وأن التصحيح يقع على الإدخال الذي أضافه التنفيذ. أُنجزت مطابقة تفصيلية في `2026-11-06-auction-native-input-map.md`: أُزيلت الحقول العامة غير المستخدمة، وأُتيحت الأقسام والنصوص الأصلية. المصدر الأصلي يثبت وجود مؤشر جوجل واحد في صفحة فك اللوحات، لذلك يُستخدم موضعه كما هو دون إضافة صفحة جديدة. لم يعد هناك سؤال معلق بشأن جوجل أو «أخرى».
